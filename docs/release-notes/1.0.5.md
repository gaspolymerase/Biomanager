## BioManager 1.0.5

### What works differently

- BioManager's website is now **[biomanager.org](https://biomanager.org)**. **Help → User guide**, the desktop app's *About* box, the server set-up page and the app's other links go there.
  - The old address still works: it sends you to the new one.

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.0.5, or download it below. Your data is kept outside the app, and a copy is taken before the database is upgraded.
- **Lab server**:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.

  Nothing in the database changes in this release. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
