# Chinese glossary (中文术语表)

The website's Chinese pages (`site/zh/`) and the app's Chinese use these
words, so a reader meets the same name for the same thing everywhere. Write
Simplified Chinese for people in a lab: plain, short, the words a Chinese
lab uses. Keep these in English: BioManager, names of files, commands,
code, and units.
