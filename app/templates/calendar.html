             {# ================= Phone feed ================= #}

            The calendar on your phone

            A private link that Apple, Google or Outlook Calendar subscribes to. It updates by itself, about every hour.

            What it shows
            Your link
            • iPhone: Settings → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar, then paste.
            • Google Calendar: Other calendars → + → From URL. Google fetches it from the internet, so it works only when the server is open to the internet.
            • Outlook: Add calendar → Subscribe from web.

            Anyone with the link can read this calendar. If it ends up somewhere it shouldn't, make a new one and the old link stops working.
