Where should the lab's BioManager run?

A lab server is one BioManager everyone in the lab signs in to, from their computers and phones. Choose where it goes; this app does the setting up and shows every step.

Only you use BioManager? You don't need a server: keep using this app, and your data stays on this computer.

{# ---- 2. Connect ---- #}

Sign in to the server

Check this computer

Cloud providers give you a key when you create the server (Oracle: the private key you downloaded; on a Mac, chmod 600 it first). The account needs sudo; on Ubuntu cloud servers that's ubuntu.

BioManager runs here in Docker, in the folder ~/BioManagerServer. Other lab computers reach it by this computer's name on the network.

    {# ---- 3. Address ---- #}

    How people will reach it

    1. In the Tailscale admin console → DNS, turn on MagicDNS and HTTPS Certificates.
    2. Under Settings → Keys, Generate auth key and paste it below. It is used once, to join the server, and isn't kept.
    3. After set-up, in Machines, open the server and Disable key expiry, or it drops off in 180 days.

    The address becomes biomanager.<your-tailnet>.ts.net, with a real certificate. Lab members install Tailscale (free for small teams), or you share the one machine with them.

    Before you start: the name's DNS record points at the server, and its firewall lets in ports 80 and 443. Let's Encrypt then issues the certificate by itself.

    The server's name on the network (or its IP address). BioManager makes its own certificate, so each lab computer installs it once; the guide shows how. If IT gives you a certificate, it can replace that later.
